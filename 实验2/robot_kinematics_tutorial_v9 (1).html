01 / 从问题出发

同一个点，为什么会有两组坐标？

一个杯子放在桌上不动，以教室门为原点测量是一组坐标，以讲台为原点测量又是另一组坐标。变的是描述方式，不是杯子的位置。

坐标系 A：参照系

规定 A 的原点以及 X、Y、Z 三个方向。我们希望把物体位置统一描述在 A 中。

坐标系 B：局部系

B 的原点可以移动，三个轴也可以旋转。同一个点 P，在 B 中有局部坐标。

我们真正要求的：已知 P 在 B 中的坐标，以及 B 相对于 A 的位置和方向，怎样计算 P 在 A 中的坐标？

先不要记矩阵。只需要想象：从 A 原点到 P，应该怎么走？ 可以分成“先到 B 原点，再沿 B 的坐标轴移动”。

02 / 几何直觉与方向余弦

坐标轴的方向数值从哪里来？先求夹角的余弦

假设 B 的 X 轴转过一个角度。我们想在 A 中写出它的方向 (a,b)。这里不用先记住 (cosθ,sinθ)：只需分别计算 B 的 X 轴与 A 的 X、Y 轴的夹角余弦。

统一规则：新坐标系的一根单位坐标轴，在原坐标系某根轴上的分量 = 这两根轴的夹角的 cos 值。每根轴都按此规则计算，正负号也由 cos 自然决定。

先以 B 的 X 轴为例：同时比较两根 A 轴

暂时让 A、B 原点重合，令 B 绕纸面垂直方向逆时针旋转 θ。取沿 XB 正方向的 单位箭头（长度为1）。分别比较它与 XA、YA 正方向的夹角：

第一个分量：与 XA 比较
r₁₁ = cos ∠(XA, XB)

当前夹角为 θ，因此第一个分量是 cosθ。

第二个分量：与 YA 比较
r₂₁ = cos ∠(YA, XB)

在0°～180°范围内，夹角为 |90°−θ|；该余弦恰好等于 sinθ。sin只是化简后的写法，原理仍是计算夹角余弦。

把方向余弦用于两个原点不重合的坐标系

现在恢复贯穿本教程的案例：B 的原点在 A 中是 (2,1)，B 相对于 A 逆时针旋转 90°。通过分别求与 A 的 X、Y 两轴的夹角余弦，我们得到 XB 方向 = (cos90°,cos0°)=(0,1)；YB 方向 = (cos180°,cos90°)=(−1,0)。两个方向都用同一种方法算出。

03 / 从方向余弦构造旋转矩阵

怎样从方向余弦构造旋转矩阵？先二维，再三维

上一章，我们已经通过夹角余弦求得 B 坐标系中单根坐标轴的方向。本章把这个方法用于 B 的全部坐标轴：二维得到 2×2 旋转矩阵，三维得到 3×3 旋转矩阵。每个数值仍使用同一规则：rij = cos ∠(A 的第 i 轴，B 的第 j 轴)。换句话说，每个数字只需回答：“B 的这根轴，在 A 的那根轴方向上占多少？”

rij = ei,A · ej,B = cos ∠(ei,A,ej,B)

这里的角是两根单位轴正方向之间的普通夹角（0°～180°）。cos 值可正、可零、可负；方向余弦并不是角度本身，也不是长度或坐标。

04 / 从旋转和平移到统一矩阵

为什么有了旋转矩阵，还需要齐次变换矩阵？

第一步：旋转矩阵解决方向转换，再加上原点位置

第3章已经说明：把 B 的 X、Y、Z 三根单位坐标轴在 A 中的方向向量 ex、ey、ez 按列排列，就得到旋转矩阵 R。但B的原点一般不在A的原点，因此除了旋转，还需要加上B原点在A中的位置 t。

R = [ ex   ey   ez ]，  pA = R pB + t

其中 R pB 将点相对于 B 原点的位移换算到 A 的方向，t 再确定 B 原点在 A 中的位置。这与第2章的“先到B原点，再沿B的轴移动”是同一个几何过程。单次转换到这里已经能完成，还不必使用齐次变换矩阵。

第二步：机械臂有多个关节，需要不断重复坐标转换

机械臂需要沿“基座 → 第1关节 → 第2关节 → 末端”逐级换坐标系。若每一步都写成 R p + t，连续两次转换会得到：

p0 = R01(R12p2 + t12) + t01
= R01R12p2 + R01t12 + t01

注意不能直接把 t12 与 t01 相加：前者需要先经过 R01 旋转，才能用同一个坐标系描述。

第三步：把旋转和平移合成一次矩阵乘法

为了让平移也能参与矩阵乘法，我们把三维点 (x,y,z) 扩展成 (x,y,z,1)，同时将 R 和 t 组成 4×4 矩阵，最后一行是 (0,0,0,1)。这样原先的“先乘旋转矩阵，再加平移向量”就统一为一次矩阵乘法。

p̃A = TAB p̃B，TAB = R₁₁R₁₂R₁₃tₓR₂₁R₂₂R₂₃tᵧR₃₁R₃₂R₃₃t𝓏0001
为什么左上角是 3×3？

三个新坐标轴，各自都要用原坐标系的三个分量描述，所以有9个方向数值。

为什么第四列是 t？

位置点最后一个坐标为1，因此 t × 1 正好加到前三个结果中。

为什么最后一行是 0 0 0 1？

让位置点变换之后的第四个坐标仍为1，同时便于多个刚体变换连乘。

这是一种计算表示法，不是一条新的物理定律。 它把已有的几何关系 pA=R pB+t 统一表达为 p̃A=T p̃B。因此多个变换可以直接写成 T02=T01T12。
补充：为什么位置点是 1，方向向量是 0？

位置点 (x,y,z,1) 应同时受旋转和平移影响；方向向量 (vx,vy,vz,0) 只表示方向，不依赖原点，因此最后一列的平移乘以0，不会影响它。这里的 1 和 0 是齐次坐标的表达规则，并不是新增的空间维度。

05 / 从列转到行

为什么矩阵的第一行能算出新坐标点在 A 中的 X 值？

按列看：第1、2、3列分别表示 B 的 X、Y、Z 单位轴在 A 的 X、Y、Z 方向上的投影。按行看：第1、2、3行分别把 B 的三个局部坐标分量投影到 A 的 X、Y、Z 轴，再加上 B 原点的位置。

先把这句话读懂：前三列是方向，前三行是计算

齐次变换矩阵的前三列记录了 B 坐标系 X、Y、Z 三根单位轴在 A 的三个轴上的投影。 换言之，一列描述“一根 B 轴朝哪里”；一行描述“B 的三根轴各贡献多少 A 的一个坐标”。第四列则描述 B 原点在 A 中的位置。

按列读：每列描述一根 B 轴
第1列：XB → (r₁₁,r₂₁,r₃₁)
第2列：YB → (r₁₂,r₂₂,r₃₂)

每个 rij 都是某根 B 轴与某根 A 轴的夹角余弦，不是沿该轴走了多少距离。

按行算：每行得到 A 中的一个坐标
第1行 → xA：三个位移的 X 投影 + tx
第2行 → yA：三个位移的 Y 投影 + ty
第3行 → zA：三个位移的 Z 投影 + tz

在 B 中沿 X、Y、Z 轴走的距离分别由 xB、yB、zB 决定。

最容易混淆的一点：“沿 B 的 X 轴走”不等于“只改变 A 的 X 坐标”。因为 XB 可能斜着指向 A 的多个轴；它的运动通常会同时改变 xA、yA、zA。

06 / 六自由度机械臂 · 正向运动学

正向运动学 FK：六个关节角怎样决定末端位姿？

现在把之前的二维坐标转换推广到真正的三维串联机械臂。已知六个旋转关节角 q₁～q₆，依次建立六次局部坐标变换，连乘后得到末端相对于基座的位置和方向。

为什么是六自由度？三维末端位置有三个分量 (x,y,z)，末端姿态有三个转动自由度。这里的六个旋转关节用于控制完整的三维位姿；但“六自由度”不意味着任意位置和姿态都能到达，还受臂长、关节限位、奇异位形等限制。

关节角从哪里来？实际机械臂通常由关节编码器等位置反馈获取关节状态，再结合零位标定、传动比及正方向约定得到 q。不同机械臂的关节轴、零位、尺寸和角度限位并不相同，因此不能把本例六个矩阵直接套用到所有六轴机械臂。本例为教学设计的运动学链，而非某品牌的 DH 参数表。

逆向运动学 IK：已知末端三维位姿，怎样反求六个关节角？

正向运动学计算 q → T。逆向运动学则给出末端希望到达的三维位置 (x,y,z)和三维姿态 R，寻找满足要求的六个关节角。以下沿用第6章同一台六轴机械臂、同一套零位与轴定义。

与原来的双连杆例子有什么区别？二维双连杆只要求目标平面位置 (x,y)，可以使用余弦定理得到解析解；六自由度机械臂要同时满足3个位置条件 + 3个姿态条件，这里使用数值迭代法求解，并展示误差和可能失败的情况。

08 / 系统理解

将坐标转换、齐次矩阵、FK 和 IK 串成一条逻辑链

1

先建立坐标系。 同一个点在不同坐标系下的数字可能不同。

2

计算轴间夹角余弦，再确定原点。 B的每根轴分别与A的各轴求夹角余弦，得到方向；乘以局部位移后再加原点坐标。

3

先构造 R，再将旋转和平移统一起来。 R p + t 写成齐次坐标形式 T p̃，便于多次变换相乘。

4

从关节到末端（FK）。 多个关节的变换矩阵连乘，求出末端位姿。

5

从末端目标回到关节（IK）。 反求能实现目标的关节角，可能多解或无解。

自测：看看是否真正理解了

问题1：为什么沿 B 的 X 轴走1单位，在90°案例中是加 (0,1)？

因为 ∠(X_A,X_B)=90°，∠(Y_A,X_B)=0°，所以 B 的 X 轴在 A 中的单位方向是 (cos90°,cos0°)=(0,1)。沿此方向走1单位，位移就是 (0,1)。

问题2：旋转矩阵中 r₁₂ 究竟是怎么得到的？

r₁₂=cos∠(X_A,Y_B)，表示 B 的 Y 轴在 A 的 X 轴方向上的分量。绕Z轴旋转θ时，这个余弦可写成 cos(θ+90°)=−sinθ。

问题3：为什么第一行可以算出 A 坐标系中的 X 值？

因为第一行保存了 B 的 X、Y、Z 三个单位轴分别在 A 的 X 方向上的投影系数，依次乘以 B 中对应的局部坐标，再加 B 原点的 X 坐标。

问题4：为什么有了 R p + t，还需要齐次变换矩阵？

R p + t 已能完成单次转换；齐次矩阵把旋转和平移合并成一次矩阵乘法，多个坐标系之间的变换就可以直接连乘。

问题5：末端三维位姿确定后，能不能唯一确定六个关节角？

不一定。即使三维位置和姿态都指定，也可能存在多个关节角配置；如果目标不可达，或受到角度限位等约束，也可能没有满足条件的解。数值算法不收敛不一定意味着数学上无解。
